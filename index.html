Welcome to the new See Tow Bus (v3.0)!

See Tow Bus turns 10 in 2026. We've completely overhauled the layout and added some new features to make navigating Singapore's bus network even faster.

You can now search bus stops by name* and stop code (in addition to nearby bus stops)

New tabbed navigation means less time finding your stop

Results loading got even (average 15%) faster, with 10 year old scripts being replaced with up to date ones.

*Searching by name requires a relatively recent phone made after 2021 otherwise it'll be very slow.

Recent browser required (must support ECMAScript 2022) for most functionality to work correctly.

Please continue to report issues on GitHub or the usual channels.
